# Reflection


While making this in Canva, I understood that digital literacy is not just a topic, it is part of our daily life.

We use phones, internet, emails every day, but we don’t always think if we are using them in the right way.

While writing these points, I realized how important it is to stay safe online, think before trusting information, and communicate properly.

Making this in a simple and human way helped me understand the topic more clearly instead of just memorizing it.

It also showed me that good presentation makes learning easier and more interesting.

Overall, this activity helped me improve both my knowledge and the way I express ideas.
